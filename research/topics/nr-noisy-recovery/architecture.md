# Application assessment and next experiment

[Recovery theorem](theorem.md) · [Ordinary baselines](architecture-baselines.md) · [Literature context](references.md) · [Topic](README.md)

The current results establish oracle advantages in fresh-frame recovery
and hidden-basis memory qualification. They do **not** yet establish a useful advantage for calibrating or
operating persistent hardware. The next investigations start from complete
device instruments and available controls, then ask whether switched outputs
improve a deployed decision. Current screens cover calibration transport,
multimode optics, displacement calibration, measurement alignment, network
entanglement, private key detection, braided magic and native computational
layers. A quantum bath or a cheaper control readout is not
enough: the comparison must include native reference encodings, ordinary
echo and spectral checks, and every accepted and rejected outcome. No checked
architecture currently meets all the required assumptions.

## What is established

[NR-R20](memory-qualification.md#nr-r20) connects the manuscript's
hidden-dephasing decision problem to an operational memory-capacity promise.
It preserves the exponential ordinary query bound, including rare long
histories, and gives an amplified switch protocol with optimal rare-burst
query scaling. A separate correlated-Pauli entropy witness certifies a
positive asymptotic storage rate from two scalar bounds. The proof components
also identify strong ordinary learners and physical clock/energy costs.
Qualifying existence of a code does not supply its encoder or decoder.
Generic hidden orientation, independent slot environments and coherent
whole-register routing remain unverified together on a native platform.

The next focused test is to identify a memory whose unavailable error
orientation follows from its actual operating interface, price the same
preparation and measurement controls for ordinary qualification, and measure
the complete cross-history process through the amplified block. A known
pointer-state pilot or accessible error records can remove the proposed
advantage. Compare qualified, usable storage after encoding calibration,
including helper survival, duty cycle, rejected attempts and reuse.
The [working-code verification bound](methods/memory-code-verification.md)
makes the deployment issue quantitative: a supplied reliable code admits
an ordinary test, so its learning and block cost must enter any claimed
end-to-end saving. The [decoder-bootstrap extension](methods/memory-code-bootstrap.md)
includes retained receiver quantum programs under an all-instance
unassisted deployment interface. Unframed high-case self-switches compile
to serial calls, while Petz inverse filters and ordinary heralded code
projection have separate yield and all-attempt ledgers. A separate
single-wire history-rank bound delimits high-dimensional storage in its
explicit opaque-error interface; it does not exclude parallel coding.

The [rare-good selection analysis](methods/memory-stream-screening.md)
tests a different end-to-end workload: screen many candidates, then
calibrate and validate a working code only on a survivor. Its conditional
expected-query saving charges that training and all rejected devices,
while retaining ordinary quantum memory and collective readout.
Classical addressing, extreme dimension/inventory, fixture time and the
missing native process remain substantial assumptions. A QA stream can
justify the access cut only when unavailable packages cannot actually be
queried coherently; a controller's chosen classical policy is insufficient.
Independent flagged loss adds a separate service constraint. In the
specified HIGH dephasing/erasure model, survival at most $2/3$ makes the
production channel antidegradable; every unassisted fixed-block logical
qubit code then has all-attempt Bell fidelity at most $3/4$. The explicit
five-use phase code has a stricter loss tolerance. These model statements
cannot be inferred from a reported efficiency alone.

The [general capacity witness](methods/unital-entropy-capacity.md)
applies to all unital channels, using entanglement fidelity and the
self-switch statistic; nonunital channels require a separately justified
imbalance or model-closeness bound. Separate proofs bound orthogonal and approximately
orthogonal unitary-error realization entropy. These certificates do not
supply a decoder or make the required coherent routing native. A prior
ordinary fidelity-only capacity bound applies to all square CPTP maps
without a unitality promise and is combined with the joint certificate.
For diluted physical Pauli errors, ordinary product probes can already
provide the required sufficient certificate. Hidden weak-product frames
admit polynomial device-call calibration with exponential classical work;
short exposures, a public tableau or specified controlled-Pauli ports
can strengthen the ordinary comparison further. These cases therefore
do not currently supply a demonstrated native advantage.

The native comparison must also locate noise in time. The
[per-slot local-noise analysis](methods/memory-native-cost.md)
gives an exponential helper-port sample penalty under fixed local
depolarization inside each opaque channel. It covers arbitrary retained
helper memory when the output target is discarded before controller
interaction. Retaining or processing that target is a separate open route;
noise applied only after sign compression has a different effect.

Retained-output comparisons must include failed attempts. The
[remote spin-phase baseline](methods/remote-spin-phase.md) matches
the proposed detected gates with an ordinary photon bus. Its stronger
compiler also matches the observed no-click spin map under calibrated,
state-independent erasure and reciprocal propagation. Spin-dependent
cavity scattering now has a full-space unresolved-loss recovery obstruction
and an ordinary entanglement-first comparison with spare matter qubits.
Its scalar reflected-sector comparison proves ordinary saturation of
average concurrence and a narrow Bell-yield interval at the cited
operating point. Coherent spectral readout needs a separate full-record
analysis. A fixed-marginal rank reduction now supplies the optimal
Bell-assistance formula for an arbitrary fully accessible purifying
photon helper, with at most eight effective measurement outcomes.
A certified full-Gaussian ordinary witness includes the temporal modes;
its joint analyzer and filtering costs still need a physical ledger.
Four coherent modes saturate larger path registers in the declared
constant-optics bus class, reducing the fixed-spin comparison to a small
attainable optimization. A coefficient-independent reverse-order compiler
also matches the stated eigen-source survivor instrument. Neither result
supplies a completion of the loss records or bounds adaptive spin controls.
An exact local-phase correction cone also makes the unknown-input gate
test finite. For the specified resonant opposite-phase responses,
ordinary photon preparation and readout attain the declared one-pass
ceiling for accepted reflected gates. This does not settle arbitrary
unequal responses or finite-bandwidth hardware rates. The next test
is a certified gate-cone comparison at unbalanced responses using full
pulse integrals, followed by the actual control, loss and clock ledger.
Encoded recovery, resolved loss records and matched control/clock costs
remain physical tests. The [partial thermal-attenuator analysis](methods/thermal-attenuator.md)
separately excludes exact heralded recovery in its infinite-oscillator
model and supplies ordinary source-preparation comparisons; it leaves
approximate unknown-state recovery open.

[NR-R01](theorem.md) concerns physical Bell-frame restoration with a fresh
private frame for each job. For $n\geq8$, each unknown module is followed once
by calibrated local depolarization, with per-qubit strength
$\eta_n=(4/3)(1-0.9^{1/n})$. The receiver must return a physical quantum output
or reject; a passive reference remains inaccessible. Counting every outcome
and allowing arbitrary ordinary memory, coding, adaptation and rare long
learning paths, the two-call switch scores at least $0.7135$, whereas every
ordinary receiver with expected cost at most two module calls scores at most
$0.690605$ (rounded upward). The stated control-visibility variant retains a gap.

This is a mathematical comparison within its interface, supported by the
repository proofs and checks. It is not a persistent-device calibration
theorem, a runtime comparison or a demonstrated fault-tolerant architecture.
The noise layer follows each entire module; it does not represent faults
throughout every gate used to compile that module. Its per-site strength
decreases with $n$. Reusing a frame, providing environment records, or adding
native mode controls changes the inference problem.

## Real workloads and the model mismatch

### Fresh private frames and delegated computation

Privacy can explain why a recovery provider lacks a frame key, but it does
not by itself establish NR-R01's complete interface. The natural Clifford
variant is already covered by [NR-R06](architecture-baselines.md#nr-r06):
Clifford-conjugated Pauli axes with physical Pauli noise are channels in
the public Pauli basis. Ordinary Bell queries sample their actual error
labels and simulate the full switch without learning or revealing the key.
Frame freshness does not remove that simulation. NR-R01 instead requires
its much stronger approximate sixth-design condition; Clifford frames alone
do not satisfy the theorem's premise.

Ordinary blind computation also need not conceal every error record.
[Baranes et al.](https://arxiv.org/html/2505.21621v1) let the server extract
syndromes while the client tracks a private Pauli frame and decodes the
communicated outcomes. This is a specific interactive architecture, not a
universal optimality claim, but it prevents treating blindness as a general
ban on checks or feedforward. The
[distributed solid-state experiment of Wei et al.](https://doi.org/10.1126/science.adu6894)
uses photon measurements and client records for blind matter-qubit gates;
it does not supply NR-R01's two coherent opaque module ports.

A surviving delegated-computation proposal must justify why the source is
offline after issuing the scrambled challenge, why no useful frame-correlated
program or native check can be provided, and how the efficient sixth-design
module circuit retains the stated post-module noise model. It must then
compare a useful confidential computation or recovery task with ordinary
blind error correction, including communication and client latency. The
existing privacy protocols do not currently provide that application.

### Gate-layer calibration and scheduling

Choosing echo settings, concurrent gate groups and recalibration times is a
real persistent workload. For example, [Wu et al.](https://arxiv.org/abs/2610.11477)
study parallel calibration and drift maintenance using ordinary simultaneous
benchmarking. A proposed switch diagnostic must predict the error of the
actual production cycle. Sequential isolated modules need not reveal
crosstalk that occurs only during overlapping pulses.

Full global tomography is an unnecessarily weak default comparator.
[Cycle benchmarking](https://doi.org/10.1038/s41467-019-13068-7) estimates cycle
performance under its randomization and noise assumptions;
[gate-set shadows](https://doi.org/10.1038/s41467-023-39382-9) reuse random
sequence data for multiple gate-set properties. Local or sparse model fitting
can also be appropriate when its assumptions fit the device. Calibration
data and computation must be amortized across subsequent settings and jobs.

The [phase-calibration benchmark NR-R15](metrology.md) checks a stronger
positive starting point: a known switch protocol exceeds every ordinary
strategy restricted to two independent phase/amplitude-damping queries.
An exact dual certificate supports that comparison. It still does not
give an unrestricted calibration rate: an explicit three-query ordinary
feedback round beats the plain two-call switch's information per query, and randomized
launches beat it at mean cost two. A retained cold bath also admits an
ordinary two-visit echo that beats the independent-slot switch. The next
comparison must therefore use actual reset, timing, return and interrogation
rules rather than import a hard two-query bound as a throughput theorem.

The [known-auxiliary-gate comparison](metrology.md#nr-r15-known-control-qec)
supplies another ordinary baseline: known controlled gates placed before
and after one common unknown sensing interval reproduce its full switched
instrument. Coherent forward/backward signal access is a separate physical
resource. Identical classical direction channels can have different joint
bath extensions; in the specified same-signed-noise extension, an ordinary
probe eigenstate lets the helper sense directly without error correction.
The next device test must establish that joint extension and price the same
sign control, helper lifetime and readout in both protocols. The comparison
does not audit every implementation of time-direction control.

The [drifting measurement-alignment benchmark NR-R18](alignment.md) makes
that distinction in an unread-meter model. It proves a finite advantage
under a strict two-call cap, with an exact ordinary adaptive certificate.
Ordinary background-free tests already have the same small-angle scaling.
The [calibrated-reuse construction](alignment.md#nr-r18-calibrated-reuse)
is stronger under an expected-call budget: within-round calibration and
one clean memory give quadratically growing local information at a
shrinking positive nominal angle. Randomly launching those longer rounds
makes the information grow even at mean cost two, with every calibration
call counted. This keeps the strict two-call theorem intact and requires
increasing frame stability, memory lifetime and accurate known controls.
It does not establish a uniform estimation-error or time advantage.
Accessible consistent measurement labels also change the comparison.
Fixed control background destroys the ideal local null advantage. An
application must explain why two modules share a frame
throughout a round, why it is fresh before the next round, and why useful
records and pilots are unavailable. Existing polarization tracking and
recorded-meter experiments do not yet supply that full interface.

A switch minus probability measures Kraus-commutator information, which need
not equal a useful scheduling quantity. Commuting channel superoperators can
produce a nonzero signal. Weak coherent errors can produce a fourth-order
signal even when ordinary repeated sequences amplify their generators.
[NR-R06](architecture-baselines.md#nr-r06) gives exact ordinary screens for
calibrated orthogonal-unitary faults and a continuous-angle scalar example.
These do not settle hardware cost: Bell probes require preparation, storage
and readout, while the switch requires coherent routing and a clean control.
The [one-sided Bell/statistic construction](architecture-baselines.md#nr-r06-pauli-statistic-memory)
needs a reference bank only for one channel, followed by a product probe
or one-helper Pauli check for the other. Its calibrated global-reference
noise correction differs from weight-dependent local noise. Existing
many-eigenvalue learning bounds do not lower-bound this scalar task.

The [local-overlap estimator](architecture-baselines.md#nr-r06-local-overlap)
needs no reference bank: its ideal variance is controlled by overlap
of the two physical error supports, with explicit readout-contrast and
calibration costs. The [local Pauli-Lindblad baseline](architecture-baselines.md#nr-r06-local-lindblad-statistic)
uses low-weight product probes and calibrated fixed-SPAM ratios even
for full-support error laws. Its positive local eigenvalue, trusted
randomizer, graph and stationarity premises must be verified.
The [spectral-concentration closure](architecture-baselines.md#nr-r06-pauli-spectral-closure)
also excludes a direct hidden-spike lower-bound reduction, and the
[cross-pair coset construction](architecture-baselines.md#nr-r06-pauli-coset-scalar)
gives an explicit general partial-reference query upper bound with
substantial classical processing. None establishes the optimal
ordinary frontier. A remaining test needs a constant task signal
outside these efficient regimes, a reason for its hidden correlations,
and [actual mixed-payload channel ports](architecture-baselines.md#nr-r06-pauli-physical-ports).
Large time-bin dimension or one coherent router alone supplies
neither that noise instrument nor a useful logical-output guarantee.

For a two-photon unitary reordering certificate, the
[passive-probe baseline in NR-R06](architecture-baselines.md#nr-r06-passive-reordering)
uses two Fock seeds and passive mode mixing to estimate the phase-invariant
process fidelity with dimension-independent variance. It uses four photons,
four pair-module traversals and destructive copy interference. Source
heralds, mode matching and detector losses remain costs. Commuting and
anticommuting unitaries both have fidelity one, so their familiar switch
decision separation does not provide a lower bound for this compilation
task. For noisy maps the same method measures a Choi overlap, a different
statistic from switch visibility.

There is also a fixed-rate limitation for raw full-register computation.
The [terminal-noise bound in NR-R06](architecture-baselines.md#nr-r06-terminal-noise)
allows arbitrary recovery on both the quantum control and data. A terminal
tensor-product noise layer still makes its accepted correct universal-gate
weight decrease exponentially with register size. This includes amplitude
damping and does not require a known common eigenbasis. A surviving
large-register application must therefore state its useful output and
logical encoding. A [local-output strengthening](architecture-baselines.md#nr-r06-local-output-noise)
covers a different common model: terminal depolarization in both slots.
After discarding the bulk, the complete control and retained local region
approach an ordinary measurement-controlled order even when the preceding
gates interact globally. This is a channel bound with an explicit finite
noise/size dependence, not an inference from low Bell fidelity. It leaves
global decoding before discard and exposed syndrome records outside its
scope. Both arguments assume actual terminal layers; neither replaces a
continuously interacting open-system calculation.

### Microwave readout with complete noise and idler ports

Amplifier backaction and inefficient qubit measurement are real architecture
bottlenecks. The [readout-noise floor](architecture-baselines.md#nr-r06-readout-noise-floor)
holds the actual cavity response and loading fixed, includes every thermal
input, and compares a concrete order-controlled router with ordinary
directional reservoir engineering. Its passive-network bound does not
cover active gain, squeezed inputs or corrected conditional outputs.

The [conditional microwave comparison](architecture-baselines.md#nr-r06-conditional-microwave-readout)
retains the correlated idler, independent loss ports, pump phases and
complete measurement record. Established ordinary interference, time-gated
isolation and likelihood processing are material comparators. A quieter
selected output does not by itself reduce earlier qubit disturbance.
Known squeezing/displacement preparation also has an ordinary qubit-assisted
implementation; a restriction to Gaussian probes is insufficient.

The remaining finite test needs an actual coherent helper circuit at fixed
pump and bandwidth budgets. Compare its complete assignment-error, time
and qubit-disturbance frontier with optimized ordinary correlated-arm
receivers and available conditional controls. Measure gain drift and reuse
calibration over its real window. No such native advantage is established.

### Displacement-area calibration with a complete optical budget

Transverse optical displacement experiments provide a concrete signal
and a real implementation, rather than only a calibration analogy. The
[displacement result NR-R16](geometric-calibration.md) compares their
one-use interface with the published ordinary conditional-force echo,
a bus-returning loop and classically varied shot orders. Initial probe
energy, maximum energy, repeatable component values and access to later
preparation are different resources. An initial-energy bound with the
same oracle order in every shot does not settle a reusable two-setting
calibration experiment. Native cavity conditional-displacement signal
processing is also an ordinary hardware comparator.

The next finite test is the complete single-photon optical echo, including
polarization-controlled spatial parity, repeat passes, aperture, source
conditioning and every detector port. Measure its launch-normalized
information or global calibration error against the switch at the same
number of displacement elements and drift window. NR-R16 gives the local
loss/visibility threshold and identifies which measured component facts
still fall short of a full comparison. No new native gain follows from
those component values alone.

### Correlated dephasing and live quantum memories

Two concrete tasks already have strong ordinary recovery loops.
[Kurilovich et al.](https://doi.org/10.1103/1bl4-b2f7) identify correlated phase
bursts using monitor measurements and code records, with echo mitigation.
[Loenen et al.](https://doi.org/10.1103/zgm8-6b8l) preserve nuclear-spin memory
during network attempts using spectator information, including both
measurement/feedforward and a gate-based alternative. The appropriate
endpoints are retained entanglement, logical error or usable Bell pairs per
second, including the disturbance and latency of monitoring.

For classical rotations about a common $Z$ axis, every realization commutes:
the elementary switch commutator signal is zero for any phase-correlation
law. Ordinary Ramsey/echo and spectator measurements can still detect severe
memory errors. For calibrated orthogonal rotation axes, two ordinary Bell
probes reproduce the scalar signal in the stated classical-angle model;
other ordinary quadratures can expose sign correlations that it misses.
These scoped screens are recorded in
[NR-R06](architecture-baselines.md#nr-r06).

For deterministic storage under calibrated Pauli noise, an ordinary echo
with one helper and two local controlled-Pauli gates attains at least the
bare switch's best entanglement fidelity. Tensor-product qutrit Weyl noise
has a corresponding construction supported on at most two qutrits. The
[full comparison](architecture-baselines.md#nr-r06-deterministic-pauli-weyl)
includes common control preparation faults and a common final control-noise
channel, with the helper phase applied before that noise. The dominant error
labels, corrections and decoder still require calibration, and the check
gates have real errors. Noise around arbitrary ideal gates need not obey
the shared-net-error model used by this theorem. The next storage comparison
therefore needs the actual gate sequence, in-circuit helper faults and a
useful output or heralded frontier beyond these closed models.

An [encoded-Pauli output comparison](architecture-baselines.md#nr-r06-encoded-pauli)
also addresses an order control carrying input information. On the specified
two-qubit code, ordinary decoding stores the logical state in that clean
control while two target queries and retained error reads reproduce the
full switched output. The same access permits perfect storage with the
complete classical error record. Two nondemolition reads can be replaced
by two coherent record qubits and their gates. Their memory, coupling,
latency and failures are substantive resources, especially for a retained
single photon. This enlarges the source's fixed-map comparator; its
restricted inequalities remain valid. Generic in-loop helper noise and
signal evolution on the decoded target need separate timed instruments.

Quantum correlations do not by themselves remove ordinary alternatives:
[two-qubit quantum-noise spectroscopy](https://doi.org/10.1103/PRXQuantum.1.010305)
accesses cross spectra under its noise model without entangled preparation
or joint readout. A time-routed switch could probe a different joint process,
but its bath history, arrival times, reset and probe backaction must then be
specified. Marginal channel maps alone do not determine that interface;
[latent-time-correlation protocols](https://doi.org/10.1103/PhysRevResearch.3.043147)
make this distinction explicit. A generic switch-based burst alarm is not
supported by the current evidence.

The [shared-bath calibration screen NR-R14](backaction.md#nr-r14) makes the
calibration problem concrete: identical Ramsey data can require opposite
echo-versus-no-pulse storage decisions. Under its native pure-dephasing
coupling, however, an ordinary echo reproduces the complete phase-resolved
switched bath/reference instrument and every later adaptive utility.
Known sensor-only interventions around a shared unknown bath interaction
also have ordinary controlled-dilation implementations. Limited echo data
need not predict a held-out uninterrupted decoupling sequence, so direct
target-sequence calibration and pump/reset/record tests remain comparators.
This is a calibration-transport screen, not an architecture advantage or a
general exclusion of unknown joint interventions. The
[high-order transfer test](backaction.md#nr-r14-high-order-transfer)
strengthens this to complete diagnostic outputs on proper bath subsets.
Ordinary fourth-order phase cycling, direct logical Bell-null tests and
validated process-learning/DD models are the relevant comparators.
The next target must predict many useful production histories within
one justified drift window, with their preparation and training costs.

The [excitation-exchange example in NR-R14](backaction.md#nr-r14) now
tests that broader setting explicitly. Two cold-spectator models have
identical isolated sensor channels and identical complete order-control
readout, but require opposite gate orders to preserve memory. Retaining
the quantum sensor output distinguishes them, with the same optimal
score already attained by an ordinary serial experiment. A native
coherent selector, when it is actually supplied, also has a chronological
implementation. Neither reduced-channel calibration nor a phase-complete
order fringe alone determines the useful production schedule.

The [unknown-coupler benchmark NR-R19](backaction.md#nr-r19) is a separate
oracle family. A switch corrects arbitrary static station phases in two
queries; an exact ordinary implementation with at most two queries is
impossible for data dimension at least three, even with arbitrary known
controls and memory. The qutrit rank-one-reflection ensemble also has a
certified finite Bell-fidelity margin against arbitrary terminating ordinary
strategies with mean query budget two. This budget is averaged over the
stated fresh prior and Bell input; prior oracle-dependent advice changes
the model. The exact bound, stopping reduction and certificate are owned
by NR-R19.

An executable address-selective reflection gives an ordinary two-query
wrapper even when its matrix is unknown. Persistent reflection data can
also be learned through a classical-address port independently of the
station phases. A supplied coherent setting selector or an Abelian qubit
subfamily gives further shortcuts, and the general family admits a
three-call simulation. In passive mobile devices the extra nominal query
can use a vacuum dummy, so its physical penalty needs an occupied-path
calculation. Generic manifold hopping and reciprocal reverse propagation
do not automatically implement the promised unknown couplers.

The next native test needs packaged modules receiving the complete coherent
address/data register, a useful task requiring that address coherence,
and an explanation of why the ordinary reflection wrapper is unavailable.
Measure the reflection drift window and the full switched instrument, then
compare ordinary calibration reuse and three-window routing at matched
primitive operations, delay, clean memory, loss and retained records. No
complete device/task combination with a convincing benefit has been verified.

The [Andreev-reflection screen](backaction.md#nr-r19-andreev) makes one
superconducting candidate more precise. A single Majorana mode gives a
rank-one reflection rather than the required full balanced exchange.
Particle-hole symmetry also restricts full converters to a different prior,
and finite bandwidth introduces pulse error. Those restrictions prevent
direct use of NR-R19's full-Haar fidelity certificate. A surviving converter
needs enough bright modes, its own symmetry-respecting comparison and the
complete ordinary reflection/routing baselines. These conclusions concern
the stated models, rather than all superconducting switches.

The [passive-converter matching test](backaction.md#nr-r19-passive-converter)
separately treats lossless on-resonance stationary scattering with unequal
external linewidths;
complete conversion requires matching every linewidth-normalized singular
mode. A timed closed-system exchange has a different pulse condition.
The [equal-power Bragg-scattering screen](backaction.md#nr-r19-bragg-rank)
also shows why many frequency modes alone do not supply the required
converter: its single interaction has only one inter-band bright mode
for the stated physical band split. Extra couplings, different pumps or
encodings require their actual propagator. The next device test must
measure the complete arbitrary-input conversion and reflected/noise ports,
then establish the second station's special correlation and full routed
interface. These matching guards do not certify finite bandwidth or a
native task advantage.

The [holonomic native-pair construction](backaction.md#nr-r19-holonomic-controls)
now builds the required correlation explicitly, but its individually
driven legs also give a cheaper ordinary two-loop target without learning
the unknown frames. The [adiabatic-port guard](backaction.md#nr-r19-adiabatic-port)
requires both endpoint manifolds, while the
[BDI comparison](backaction.md#nr-r19-bdi-controls) closes the stated
common known symmetry-frame family. A surviving native coupler must
justify why those actual controls or symmetry wrappers are absent and
establish the complete finite-band input/reference instrument.

There is a named optical testbed with a longer-lived oscillator:
[Spinnler et al.](https://doi.org/10.1038/s41467-024-53882-2) couple a quantum
dot to a phononic-crystal mode with frequency $1.466\,\mathrm{GHz}$,
quality factor $2100$, coupling $g_{\mathrm{ep}}/(2\pi)=2.9\,\mathrm{MHz}$
and thermal occupation about $58$ at $4.2\,\mathrm K$. The corresponding
energy-ringdown time $Q/\Omega$ is about $228\,\mathrm{ns}$, whereas the
QD excited-state (negative-trion) lifetime is $1.18\,\mathrm{ns}$. Those
scales permit a bath-memory calculation across optical histories; they do
not establish coherent overlap
of all radiative and other environmental records. The demonstrated response
admits a classical mechanical approximation and is measured by ordinary
photon autocorrelation spectroscopy. Sideband driving, cooling and heralding
are further ordinary baselines. A useful comparison must keep the optical
and mechanical outputs and their reset dynamics, rather than infer quantum
utility from the oscillator lifetime.

This engineered mode must not be conflated with a bulk acoustic bath.
[McCutcheon's quantum-dot model](https://doi.org/10.1103/PhysRevA.93.022119)
uses an acoustic cutoff $\omega_c=2.2\,\mathrm{ps}^{-1}$, whose inverse is a
characteristic cutoff timescale of about $0.455\,\mathrm{ps}$, and exposes
non-Markovian effects in ordinary emission spectra. Such a model does not by itself preserve bath
coherence over nanosecond order routing. Pulse profiles and complete
two-history overlaps remain necessary in either regime.

### A coherent mechanical memory and its ordinary control benchmark

[Bozkurt et al.](https://doi.org/10.1038/s41567-025-02975-w)
([primary preprint](https://arxiv.org/html/2412.08006v1)) demonstrate a
transmon-coupled silicon mechanical oscillator with state transfer and
nonclassical state tomography. Its intrinsic energy lifetime is about
$25\,\mathrm{ms}$; measured coherence of the zero/one-phonon code is
$64\,\mu\mathrm{s}$, extended by ordinary Hahn echo to
$562\,\mu\mathrm{s}$ and two-pulse Carr--Purcell control to
$1.02\,\mathrm{ms}$. These are distinct performance measures. The
qubit-mediated preparation fidelity is $0.711$, and oscillator B's
coupled qubit has $T_1/T_2^*=1.55/1.05\,\mu\mathrm{s}$. Extra transfers
and control operations therefore require their actual errors and durations.
The demonstrated preparation, swaps, rotations and readout already provide
strong ordinary storage controls.

Other long-lived phononic environments establish different resources.
[Odeh et al.](https://doi.org/10.1038/s41567-024-02740-5)
([primary preprint](https://arxiv.org/html/2312.01031v1)) observe population
memory in a dense weakly coupled defect bath, described by Solomon
equations. A roughly $34\,\mu\mathrm{s}$ defect population lifetime does
not establish an isolated coherent exchange bus. Their ordinary hole-burning
and ground/excited probe sequences are reset/history comparators.
[Fechant et al.](https://arxiv.org/html/2610.21853v1) infer intrinsic TLS
relaxation exceeding one second from pump--probe data, while leaving
intrinsic coherence open and describing overdamped exchange. Detuning,
active qubit reset and retained jump-conditioned records are ordinary
available resources; the lifetime fit does not certify one-second quantum
storage or coherent order control.

The coherent oscillator supplies a concrete task: preserve a loaded
zero/one-code state over declared storage durations. Fix a training budget
to choose between ordinary swap--store--read, demonstrated echo/CP and a
proposed two-profile strategy. Freeze those controls, then measure storage
entanglement fidelity against a reference on held-out durations or drift
windows. Match input code, total elapsed storage, output state and final
reset tolerance. Charge training, every successful and failed production
launch, transfer/control pulses, helper preparation/readout, idle/routing
time and restoration of the retained memory. Passive waiting and active
swap-and-qubit-reset are both ordinary comparators, with their actual
thermal floor, transfer error and reset time.

The missing interface is coherent choice between two unknown joint
interaction profiles. Classical DC, flux or Stark settings do not supply
it. Establish that choice physically and reconstruct the phase-resolved
helper/oscillator instrument, retaining leakage, microscopic memory and
output-field records. If the available operation is the
[native selector in NR-R14](backaction.md#native-coherent-settings-records-and-the-physical-ledger),
its ordinary chronological implementation already reproduces the full
instrument with the same retained memory. A different routed interface
must specify its real ports and delays. No held-out task or total-cost
advantage has yet been established on this hardware.

### Encoded bosonic storage and available ordinary controls

Bosonic loss and Gaussian shift correction are concrete memory bottlenecks.
The [calibrated compilers in NR-R06](architecture-baselines.md#nr-r06-bosonic-compilers)
reproduce the entire switched channel for two pure-loss channels, two
quantum-limited amplifiers, or two centered isotropic Gaussian displacement
channels. Two known conditional number phases or conditional displacements
around the same serial noise calls suffice. Equality precedes encoding or
recovery, so finite-energy cat, binomial and GKP states do not evade it.
Native cavity-ancilla experiments establish these ordinary primitives,
while their drive energy, duration, control noise and memory exposure
remain charged. No measured switched bosonic memory or timing winner is
established by the component values.

The [anisotropic and ideal-GKP comparison](architecture-baselines.md#nr-r06-anisotropic-gkp)
keeps a distinct limitation: anisotropy can defeat the independent random
displacement compiler, while a known logical-parity echo still matches
the best deterministic entanglement fidelity allowed by one switch
control qubit in the specified ideal diagonal-Gaussian code model. The
argument requires an exact final syndrome while the control stays
coherent. The separate [finite-energy component](methods/bosonic-logical-frontier.md)
derives a normalizable encoding and proves fixed product-decoder plus-flag
dominance by ordinary Fourier alignment and finite squeezing. The bound
extends to arbitrary deterministic control/logical recovery after the
fixed gauge trace. Retaining the physical gauge coherently can preserve
additional recovery information, as exact ordinary counterexamples show.
Its energy ledger includes transient occupation. A finite-cost decoder,
equal-energy optimization and full coherent Gaussian recovery remain open.
The separate [heat-code recovery certificate](methods/heat-gkp-certification.md)
uses the standard oscillator heat envelope with its full Gram normalizer.
It bounds input and Gaussian-circuit output photon tails uniformly over
logical/reference inputs, including transient squeezing. A common
ensemble mean-energy ledger supports an explicit finite-code ordinary
recovery. At the declared noise point its all-attempt Bell fidelity
exceeds a code-independent upper bound for one raw Weyl switch, retaining
the entire control/target output and allowing any target-only encoder.
The raw-switch bound has no energy restriction. It excludes intermediate
framing and repeated switched blocks; it does not settle the heralded
frontier or validate a physical decoder.

The [non-Gaussian cat-reservoir comparison](architecture-baselines.md#nr-r06-cat-reservoir-parity)
retains the actual warm bath and finite buffer. An ordinary coherent
parity wrapper reads total odd-jump parity without measuring the initial
logical parity. The small-time switch flag has distinct loss and heating
records; it is not a certified loss-only syndrome. A useful extension
needs the complete physical order interface and finite-time heralded
memory frontier beyond this available ordinary record. The
[whole-mode route analysis](architecture-baselines.md#nr-r06-cat-physical-route)
now keeps the vacuum dummy, persistent buffers and all four physical
station opportunities. Its literal native ordinary construction retains
helper-dependent phases and gate faults; a pumped cat reservoir is not
an inactive vacuum port. The next action is calibrated parity-tagged
pump scheduling on an integrated finite-energy device before optimizing
an abstract two-slot switch.

A distinct [finite-energy Jaynes--Cummings benchmark](architecture-baselines.md#nr-r06-jc-energy)
concerns discrimination of commuting and anticommuting rotations, with one
noisy coherent-field gate and one ideal gate. For its physical equatorial
prior, an explicit ordinary circuit and completed measurement dominate the
specified switch readout at every positive field energy. It uses the same
one-field photon budget, plus Bell preparation, a known isometry and joint
readout, and a qubit plus qutrit of memory through the noisy call. Those
control and memory costs remain charged. The source's restricted isotropic
and four-box comparisons remain distinct. The next energetic comparison
needs a useful workload and the total physical energy, time and memory
budget, including the actual selector or no-atom port and field reuse.

There is a real whole-mode routing primitive:
[Chapman et al.](https://doi.org/10.1103/PRXQuantum.4.020355) demonstrate
a transmon-controlled swap of two high-Q cavity modes in $1.3$ $\mu$s.
Their reported measurement-corrected Bell estimate is not an
arbitrary-input/reference process bound or a switched noise instrument.
A second mode, coupler, pumps and coherent control are physical resources;
the second mode also belongs in ordinary storage comparisons with its
actual noise. A two-station, two-window proposal must account for all four
module opportunities when both modes are exposed in both windows.
Displacement noise excites an unused vacuum mode, and bath timing or dummy
outputs can retain order information. The complete instrument needs to
erase those records or specify a real inactive-module interface.

This is a calibrated storage comparison. Its helper randomization depends
on the noise parameters and supplies no unknown-parameter sensing converse.
Thermal loss, mixed gain/loss, anisotropic shifts and actual engineered
dissipation need separate instruments and strong ordinary QEC comparators.
Any control must remain a real independent system through vacuum; a path
carried only by a lost packet does not supply that memory. A clean control
or protected routing mode also offers input-storage alternatives when
the native encoder can use it.

### Multimode pointer retention

This is the closest operational interpretation of the main paper's fixed
unknown-dephaser model. For complete rank-one dephasers in bases
$\{|u_i\rangle\}$ and $\{|v_j\rangle\}$,

$$
v=\frac1D\sum_{ij}|\langle u_i|v_j\rangle|^4,
\qquad p_-=\frac{1-v}{2}.
$$

Here $v$ is the average survival of a uniformly chosen first-basis pointer
label after the second dephaser. The same unknown basis may persist across
all calibration calls in the channel-only model. A Choi-overlap experiment
has signal $v/D$, but this particular comparator is not an ordinary lower
bound.

Native access can eliminate that suppression. If an encoder prepares
$|u_i\rangle$ and a decoder tests its label, one call to the second module
gives a Bernoulli retention sample. If the first module supplies stable
Lüders outcome records, the ordinary sequence $E$–$F$–$E$ on $I/D$ estimates
$v$ by comparing its first and last labels. Neither method needs a classical
description of the basis. [NR-R08](architecture-baselines.md#nr-r08) states
these shortcuts and the separate role of the number of unread sectors.

Complete rank-one dephasing is entanglement breaking. This interpretation
therefore concerns classical pointer retention, rather than storage of an
arbitrary logical qubit. Quantum-memory applications require the actual
degenerate sectors or noiseless matrix factors, plus an executable encoder
and decoder. Demonstrated
[dynamically generated protected memories](https://doi.org/10.1088/1361-6633/ad6805)
use known symmetry and control structure;
[direct unknown-subspace discovery](https://doi.org/10.1103/PhysRevA.86.052101)
is also an ordinary baseline. A large protected sector is not evidence of
many hidden measurement outcomes.
The [memory-algebra task](architecture-baselines.md#nr-r08-memory-algebra)
now defines a qualification decision for a promised conditional
expectation. Its full self-switch output cannot enlarge the existing
quantum factor. For exact uniform rank-n Pauli-subgroup noise, the
[random-stabilizer ordinary estimator](architecture-baselines.md#nr-r08-subgroup-ordinary)
uses polynomially many calls and no extra reference qubits. A surviving
resource comparison needs the actual subgroup/rank promise, noise
robustness, encoder usefulness, frame stability and routing cost.

A spectral bath needs a separate independence test. The
[shared-clock result in NR-R08](architecture-baselines.md#nr-r08) gives
two perfectly dephasing sections whose joint spatial channel is far from
their independent composition. It also bounds the bandwidth times delay
span needed for one shared frequency register to emulate independent
MUB measurements. The quadratic dimension cost is robust in diamond
distance. This concerns controlled delays with bounded spectral support;
separate material baths can supply different records. A reported spectral
width alone is insufficient, and delay span is not automatically the
clock period of a stationary source.

The [material-pointer array](architecture-baselines.md#nr-r08-material-pointer-clock)
provides a different, explicit record dilation using cavity-QND primitives.
The demonstrated binary gates do not yet supply the complete high-dimensional
unknown-basis pair. A common-finish three-window ordinary compiler includes
the private pointers and native vacuum action. Markov timing kernels and
available pointer echo can close proposed coherence margins. The remaining
experiment must measure noncommuting write/storage dynamics and their
cross-history kernels, including actual echo errors, reset emissions and
calibration reuse. A memory lifetime alone supplies no such comparison.
The [mechanical strength test](architecture-baselines.md#nr-r08-mechanical-record-strength)
separates nonzero record rank from useful pinching. Its
[full-clock model](architecture-baselines.md#nr-r08-mechanical-clock)
retains thermal purification and emitted fields, with exact closed-loop
ordinary basis control when native inverse/force ports exist. Before a
task comparison, certify the actual strength and complex history kernel
at one operating point; do not combine unrelated coupling, temperature
and linewidth values. Strong preserved-photon records outside these
ordinary controls remain unverified.
For the declared mixed-input SAME/MUB decision, the full clock model
also supplies ordinary recurrence error laws, an identical-module
finite-launch garbling and a closed-model Chernoff benchmark. Its
remaining possible benefit concerns complete time/energy cost with
actual damping, pulse duration, failed launches and reset, rather than
per-launch helper contrast.

Actual large-mode interconnects already use targeted ordinary tools.
[Li, Ryczkowski and Genty](https://doi.org/10.1364/OE.558061) measure
spatial coherence and vary source bandwidth;
[Engineer et al.](https://doi.org/10.1103/bwd5-wx7j) certify channel
dimension with a small set of calibrated preparation/measurement bases.
Those production encoders, narrowband or spectral pilots, and readout
records must be included before claiming a hidden-basis advantage.
For stationary frequency-diagonal illumination, purification can carry
a record even while the outgoing local frequency state does not reveal
the pointer label. Readable arrival labels require a physical measurement
model, rather than an inference from bandwidth.

## Why a photonic implementation needs an instrument-first test

Unmonitored phase averaging is physically plausible, but a frozen multimode
fiber implements predominantly coherent transport, not complete pinching.
An averaged model
$E(\rho)=\int p(x)T(x)\rho T(x)^\dagger\,dx$
reduces to fixed-basis dephasing only under additional conditions. A local
approximation $T(x)\simeq T_0e^{ixQ}$ requires accounting for the transport
$T_0$, checking one generator over the relevant range, and measuring the
remaining off-diagonal coherence. Loss, polarization mixing and leakage
must be included.

Ordinary optical access is powerful. A
[reconfigurable multiplexed quantum photonic network](https://doi.org/10.1038/s41566-025-01806-x)
characterizes its multimode mixer with classical light and a camera.
[Measured transmission matrices](https://doi.org/10.1103/PhysRevX.11.021060)
identify deformation-resilient modes. An unavailable environmental record
does not forbid pilots: pilots measure the probe output. Learning the
transport or delay modes may also supply the native pointer controls needed
for the direct retention test.

There is a narrower motivation for quantum-level verification after
classical stabilization.
[Stevens et al.](https://doi.org/10.1103/63wh-4x54) use simultaneous entangled
probes to detect nonunitary channel effects missed by bright polarization
tracking, with ordinary ancilla-assisted reconstruction. This supplies both
a real verification problem and a strong ordinary comparator; its
polarization-qubit setting does not establish an opaque high-dimensional
pointer channel.

The cost of an ordinary quantum reference is device specific. For a
polarization-qubit target, the path qubit used as a switch control has the
dimension of a full Bell reference. [Yoon-Ho Kim](https://doi.org/10.1103/PhysRevA.67.040301)
demonstrated deterministic preparation and measurement of all four
single-photon path/polarization Bell states using linear optics. A separate
stored photon and a probabilistic two-photon Bell analyzer are therefore
not intrinsic costs of that ordinary diagnostic.

Using this encoding still requires the full path-preserving instrument
$\mathrm{id}_{R}\otimes\mathcal E$, including off-diagonal path blocks.
Equal reduced polarization channels on two paths do not suffice: mode
dependence or arrival-time bath records may corrupt the reference. Native
preparation optics, readout ports, routing and drift must be matched. This
resource observation does not replace unknown-input recovery with destructive
tomography, and a single path qubit is not a full reference for a
high-dimensional target. No demonstrated high-dimensional memory gap is
established by the qubit example.

## Go/no-go protocol

1. **Choose a real decision.** Start with two persistent multimode modules
   under naturally occurring fluctuations. Prespecify whether the diagnostic
   triggers recalibration, selects a link pairing or validates an existing
   mode encoder. Score held-out transmission or decision error, rather than
   precision of $v$ alone. Do not impose a SAME/MUB promise or hide metadata
   that the operator possesses.
2. **Inventory native access.** Record outcome labels, phase settings,
   encoder/decoder controls, inverses, bright and multispectral pilots,
   reference wavelengths, Bell probes and quantum storage. Determine which
   information persists between jobs.
3. **Validate the physical interface.** Test the reduced-channel model,
   stationarity and drift window independently. Verify that both orders use
   the same effective forward modules: reverse propagation can implement a
   different transfer matrix. Characterize control visibility, which-order
   leakage and mode-dependent loss. Count loss and rejection as outcomes.
4. **Run the strongest admitted ordinary methods.** Include recent and
   reused transmission-matrix data, rapid pilots, direct deployed-encoding
   tests, accessible-label retention and entangled probes. Apply
   [NR-R06–08](architecture-baselines.md) before claiming a query advantage.
   In particular, [NR-R07](architecture-baselines.md#nr-r07) shows why
   persistent finite-frame families permit amortized learning; it does not
   promise a practical runtime for exhaustive classical fitting.
5. **Match resources within drift windows.** Randomize acquisition times and
   reserve held-out drift episodes. Charge optical power and detected
   photons, bandwidth and temporal resolution, all device traversals,
   routing loss, reset/readout, storage, hardware occupancy and classical
   fitting latency. For quantum-memory baselines, use measured memory cost:
   [large-scale entanglement-enhanced process learning](https://www.nature.com/articles/s41467-026-75553-0)
   already includes noisy auxiliary memory and sampling overhead.
6. **Use decisive controls.** Check known-pointer or visible-record cases,
   commuting phase noise, calibrated Pauli faults, loss-induced bias and
   timing artifacts. For a gate-layer variant also include
   simultaneous-only crosstalk. These controls test whether a new signal
   actually diagnoses the proposed failure.
7. **Proceed only on downstream benefit.** Require a prespecified,
   statistically supported gain in the held-out decision at matched total
   cost. Stop the architecture claim if ordinary calibration remains valid
   throughout the useful window, native labels recover the direct test, or
   routing and control overhead erase the benefit. A finite hardware gain
   would still require a separate argument for any asymptotic claim.

The multimode calibration candidate still requires a useful persistent pointer-like
channel, inaccessible records, no cheap pointer preparation/readout,
insufficient ordinary calibration within its drift window, and a realizable
coherent-order interface whose extra information predicts a useful action.
The checked primary sources establish individual ingredients and important
ordinary workarounds, not this combination. These assumptions need resolution
on a named device before extending the recovery theorem into an architecture
claim. This is a bounded assessment, not an exhaustive
novelty or priority claim.

### End-to-end loss inference and the passive-network test

Inferring an internal bottleneck from end-to-end probes is a real network
task. The [loss-inference screen in NR-R09](communication.md#nr-r09) separates
its statistical promise from physical access. The abstract switch can
reveal an unordered loss split beyond the serial product, but a fixed
passive network with vacuum baths is completely specified by its full
accessible field matrix. If that matrix depends only on total loss, no
quantum probe or endpoint controller reveals the split. Reflectionless
opposite-direction absorbers leave orthogonal directional loss records;
their equal transmitted channels do not realize the abstract same-port
switch through vacuum.

The next native test must identify controller-conditioned internal
interactions or another resource outside that passive model, then include
the ordinary access it permits. Alternate walks, returns, reflected
fields, local probes and nondestructive monitors cannot be omitted when
physically available. Holding total loss fixed while measuring every
accessible complex transfer amplitude provides a falsifiable first test.

## Cooling and reset-based state preparation

Complete thermal resets are a useful retained-state benchmark, but
[NR-R10](communication.md#nr-r10) gives a full ordinary simulation
using the same two channel calls, even for different unknown reset
states. Input storage and two controlled register exchanges replace
order control. Their actual duration, memory error and coupling must
be priced on the same device. For thermal bosonic inputs, native parity
or vacuum filtering supplies a stronger ordinary state-preparation
comparison than unassisted equilibrium contacts. The clean helper,
all rejected trials and replenishment belong in both accounts.

Equality of retained states does not establish equality of bath heat
or refrigerator performance. Those claims require final reservoir
records and restoration work. A new cooling candidate should specify
its incomplete or correlated relaxation instrument and compare it with
ordinary measurement, active cooling and input-memory controls; a
lower conditional temperature after full resets does not suffice.

## Distributed-computing link screen

Delivering a stored Bell pair for a remote gate is a concrete architecture
objective. [Main et al.](https://doi.org/10.1038/s41586-024-08404-x) demonstrate
distributed trapped-ion computation through a heralded optical link;
[Knaut et al.](https://doi.org/10.1038/s41586-024-07252-z) demonstrate networked
nanophotonic memory nodes. The output to compare is a usable matter Bell pair
per wall-clock time, including waiting-induced memory error.

The [communication results](communication.md) give three precise screens.
Pure absorbing-vacuum loss produces the ordinary serial erasure channel plus
a receiver-preparable flag (NR-R09). A genuinely independent EB slot gives a
one-ebit-per-use rank ceiling; mandatory control dephasing also admits an exact
known-channel simulation with one equally dephased qubit wire (NR-R10).
This does not grant a free wire to every abstract switch placement. Nor can
the local Bell-label readout of NR-R06 be imported across separated labs
without paying for joining the halves.

The [random-receiver comparison in NR-R10](communication.md#nr-r10)
preserves the existing locality advantage against its restricted side-wire
network. It also gives a full-channel ordinary parity sandwich when the
controller can act before and after every noisy target, and an ordinary GHZ
distribution protocol when a clean travelling Fredkin bus and local auxiliary
measurements are physically available. Neither access pattern follows from
an abstract global switch. The next network test must specify the actual
controller transport/fanout graph, where the unknown message is loaded,
which receivers are spatially separate, and every source, local gate,
measurement, communication and memory cost. Encoding several receivers in
one photon's degrees of freedom does not establish that distributed interface.

The elastic accepted state-carving operators in the named cavity-node model
preserve a common photon time-bin label and act on disjoint memories.
Consequently they commute Kraus by Kraus, and the entire accepted switched
instrument is already ordinary serial processing (NR-R11). Elastic contrast
errors and local spin errors preserving those labels supply no extra order
syndrome. Mode-changing scattering is a different hypothesis, not a conclusion
from the documented elastic model.

Keeping spin memories does not remove ordinary entanglement protocols.
The [retained-spin comparison](communication.md#nr-r11-retained-spin-parity)
gives full one/two-click parity instruments and a serial photon-bus
construction under their elastic spin-preserving assumptions. Separate-arm
and local logical-photon ports are not automatically available in an inline
two-dot device. The useful next test is a calibrated retained Bell pair,
including its local frame, every failed herald and reset, actual spin
readout, finite-pulse distortion and the permitted optical connections.

The remaining narrow optical candidate is retained inelastic spectral
scattering followed by a downstream frequency-dependent reflection. A
[quantum-dot waveguide analysis](https://doi.org/10.1038/s41534-023-00717-5)
identifies near-carrier incoherent scattering that cannot simply be removed
with a distant spectral filter. This is a different platform, and does not
establish that a switched circuit improves its Bell-pair yield. The next
calculation must keep outgoing frequency, which-time bath records, local
spin resets and actual photon heralds. Compare ordinary frequency-resolved
selection, commuting spectral-phase check sandwiches and coherent same-order
delayed paths, as well as both serial orders. In a two-frequency model, a
before/after controlled frequency-$Z$ check preserves a diagonal elastic
instrument and rejects cross-bin jumps. Its spectral resolution, pulse
reshaping, additional delay and helper faults must be included. If bath
emissions resolve the two histories, a switch's rejection of
half the scattered events can be ordinary path error filtration. Charge
extra loops, stabilization, conversion and control coherence on the same
physical graph. A Markov bath does not alone imply resolved histories:
overlapping photon excitation profiles can emit at the same laboratory
times. Compute their actual overlap from the pulse and preceding-node
response, rather than substituting a dephasing rate for a two-history overlap.

The [Raman exchange screen](communication.md#nr-r11-raman-swap) adds
same-helper ordinary ideal Bell-generation, remote-SWAP and detuned-serial
baselines. The [native-port analysis](communication.md#nr-r11-raman-route)
gives conditional temporal-helper routes and a comparator on the same
reconfigurable graph. Both physical counterpropagating photon ports must
be preserved; an independent helper does not fit those two simultaneous
inputs without extra modes. Rejected paths, loop extinction, temporal-code
leakage, component loss and actual slot-conditioned stationarity remain
charged. Stronger [local-memory constructions](communication.md#nr-r11-raman-local-ancillas)
use one extra stationary qubit at each node, one preserved photonic helper
degree, local coherent subspace filters and complete photon readout. No
entanglement is initially shared between nodes. They beat the stipulated
bare-switch yield in the high-transfer regime and at a separately certified
intermediate setting. Thus a product-active-spin bound cannot be extended
to these local memories. Preparation, coherent filtering, decoding,
communication and reset remain additional physical costs.

A fixed coefficient-independent projection also beats the scalar
unknown-module switch's minus-only Bell yield; it does not compare all
calibrated plus outputs. The more general ordered field-operator extension
extracts an ordinary Bell output while retaining the actual ordered kernel.
It supplies no switch comparison for arbitrary noncommuting coefficients.
The product photon/helper ports and common logical SWAP frame must be
realized by the physical Raman modes.

A separate [passive photon-filter construction](communication.md#nr-r11-raman-passive-filter)
gives a coefficient-independent ordinary Bell output with one photonic
helper and no extra retained stationary qubits. A four-level flying helper
strengthens the two-level-helper construction, using eight joint photonic
modes, a passive contraction, four readouts and a coherent local spin
filter. Additional vacuum rejection ports, mode preservation, apparatus,
failed photons and resets remain charged. These are achievable processor
families; arbitrary adaptive photon/spin controls still require comparison.

The [direct temporal filter](communication.md#nr-r11-raman-direct-temporal)
includes a physical passive source preparer and all clock/port rejections,
closing the selected symmetric ring-minus yield margin in its disjoint-slot
model. A [calibrated timed photon flip](communication.md#nr-r11-raman-late-flip)
also compares the ring's combined Bell flags in a stated transfer regime.
Its active rail control, filters, phase calibration and clock remain priced.
Closed [timed spin conjugations](communication.md#nr-r11-raman-timed-controls)
compile to photon/helper controls in the known accepted SWAP frame; this
does not identify their physical costs or their rejected bath instruments.
Finite node response can create false central-clock heralds, so a real
temporal circuit needs an [operator-level pulse/leakage certificate](communication.md#nr-r11-raman-temporal-tail).
The finite-response proof retains the actual useful wavepacket strength
and bounds Bell fidelity and yield; an observed intensity tail alone
does not supply its uniform node and environment premises.

The [balanced-cavity frontier](communication.md#nr-r11-raman-cavity-frontier)
retains complex bright, dark and spectator amplitudes. In its declared
design family, an ordinary coherent which-node route at an optimized
operating point closes the proposed raw-yield benefit from deliberately
weakening transfer when the corresponding tuning and paths are admitted.
This is an achievable design comparison,
with a narrow-pulse limit; it is not a theorem about equal clocks or the
tuning range of a fabricated device. A bare flat-channel transfer parameter
therefore does not identify the next hardware advantage.

The decisive test needs actual two-node input/output routes, measured pulse
spectra, frequency conversion, collected and lost modes, and both Raman-leg
phase frames. Model station and route phase fluctuations jointly with the
available pilots, and establish the required stationarity within each full
routed attempt. Compare the switch with coherent which-node routing,
retuned ordinary settings, adaptive ordinary attempts and local-memory
protocols wherever their ports exist. Prespecify a delivered Bell-fidelity
target and compare source photons, occupied encounters, pilot/control energy
and mean completion time, including every lost launch, failed filter,
memory reset and successful hand-off. A source wait or a nominal query count
alone settles none of those comparisons. No native rate advantage is yet
established.

The [phase-reference analysis](communication.md#nr-r11-raman-phase-reference)
distinguishes arbitrary scalar node phases from the physical Raman,
spin-frame and route phases. Coefficient-independent ordinary serial
filters already tolerate the scalar phases; they do not erase unknown
Raman frames. Reciprocal return propagation also does not automatically
conjugate a fluctuating path phase. The remaining comparison must use
retarded physical routes, a causal pilot/accepted-record model and the
admitted ordinary alternatives. Under its matched-kernel hypotheses, an
ordinary flag has the same normalized Raman/spectral response as the
switched-minus output, at lower yield. Double-herald methods require their
actual cycling-emission ports. Verify the
joint phase-noise correlations and within-route stability at the actual
signal and pilot times, then charge source duty, rejected records and
reset in the delivered-Bell rate. No measured matched SPRINT route, joint
phase-noise model or resulting native rate advantage has been established.

The finite two-frequency candidate has failed this stronger ordinary
screen: checks at each node remove all cross-bin jumps, including two
shifts that return to the original bin and evade a single global check.
Two local check sandwiches use four controlled spectral phases. Their
accepted branch can reuse one helper sequentially after plus-port selection
and reset; two simultaneously retained helpers are not a necessary cost.
The physical routing, selection and reset still count. This does not exclude
a finite hardware tradeoff with one order control.
The exact projection identity is replayed in the communication checks.
It is not a continuum scattering calculation or a fit to the named
experiment. Resolve the measured frequency kernel and price these
helpers before treating the formal noncommutation as an application.

### A local measurement must leave a usable output

The [delivered-photon screen](architecture-baselines.md#pbs-delivered-output)
tracks every photon-number sector of the recent local-measurement
implementation. An ideal ancilla-only herald can leave a target photon;
ancilla loss can also turn a two-ancilla failure into a false success with
target vacuum. Coincidence-selected states alone do not certify the
delivered output. The comparison includes the ordinary known-control
optical graph, source/data injection, detector records and the target
delay needed for feedforward. It supplies a concrete instrument test,
without establishing a native rate advantage.

### Private key detection

Quantum key distribution supplies a useful endpoint that bright classical
channel pilots cannot replace. The
[photonic proof of principle by Valibouse et al.](https://arxiv.org/html/2608.13561v2)
demonstrates control-based eavesdropping detection without disclosing raw-key
outcomes. Its measurement requires a path-entangled ancillary photon,
postselected two-photon interactions and joint path readout. An eavesdropper
can access the implemented control; the authors do not claim a secure
protocol. Retained-qubit statistics are not secret-key rates.

The displayed ideal selected instrument also has a substantial event cost.
Bob's coincidence map has Kraus operators $P_j/\sqrt2$, with success $1/2$.
For the circular system input, Alice's selected projector and the sum of
Bob's outcomes have accepted mass $1/4$ in either order: the first order
gives $\|P_i|L\rangle\|^2/2=1/4$, while the reverse uses
$\sum_jP_j|L\rangle\langle L|P_j=I/2$. Keeping all control flags preserves
that mass; unbiased same-basis sifting leaves at most
$1/8$ retained events **per generated entangled pair**, before optical loss
and detector inefficiency. This is a normalization bound for those selected
operations, not a key-yield or security bound.

[Spencer-Wood's ordinary two-way private-detection protocol](https://arxiv.org/html/2303.03893v3#S6)
already adds a terminal Alice measurement after Bob returns the measured
state. Bob can destructively measure and prepare a replacement photon in
the recorded state; this needs a source and feedforward latency, but no
order-erasing ancillary photon or preserved quantum reference. Its complete
security analysis is also unresolved, so it is a resource comparator rather
than an equally proved secure replacement. A deployable claim needs full
security and finite-key rates against ordinary one-way, biased-basis and
two-way methods, with source brightness, all postselection, transport,
readout and reset charged. The current experiment establishes no such
matched hardware advantage.

## Native computation and coherent dispatch

Quasiparticle poisoning supplies another concrete memory test. The
[graded fermionic comparison](architecture-baselines.md#nr-r06-fermionic-poisoning)
uses the even system/reservoir dilation and the final code-parity record.
In its independent isotropic tetron model, an ordinary controlled-even-parity
check dominates the specified collision-filter yield/fidelity comparison;
calibrated classical flag processing also reproduces the measured
parity-accepted code instrument. This uses one surviving helper and real
controlled bilinear gates, rather than odd Majoranas treated as unrelated
tensor factors. It does not simulate rejected odd-parity outputs or all
poisoning models. A useful native test must derive the actual contact
operators and early/late reservoir overlaps, then compare ordinary parity
monitoring at the same gate error, memory exposure, reset and rejected-launch
cost. Unequal rates or retained reservoir coherence require their own
instrument rather than importing the symmetric formula.

The [native-check baselines](architecture-baselines.md#nr-r06) also prevent
promoting a known Clifford layer or a read-only classical-bit lookup merely
because recompiling its full unitary is expensive. Cheap transported checks
can use the same native calls. Helper gates, their noise and memory must be
costed, rather than assumed free by either implementation.

Distinct commuting modules need not have identical ideal unitaries. When
their common eigenbasis is known and accessible, an ordinary coherent
basis-label check rejects off-diagonal single faults with the same Bell-good
weight as the switched plus branch. The first-order comparison does not
extend to arbitrary double faults, and copying a general basis label can
need a full register of helpers. For number-diagonal Kerr or SNAP operations,
a modular-number check supplies a more specific ordinary loss test; one
parity helper detects every first-order photon loss. These are existing
verification resources, not free controls for an unknown eigenbasis or
unavailable traveling-photon QND measurements. NR-R06 states their exact
scope, double-fault counterexample and native costs.

The [recorded parity-braid screen in NR-R08](architecture-baselines.md#nr-r08)
compares an ordinary three-parity-measurement braid with a specified balanced
switch construction using mean six parity measurements and two control
readouts. Reading the control first and skipping a dispensable final parity
measurement reduces the latter mean to $11/2$, with the same control cost.
Both use Pauli and syndrome tracking; any correction needed to return an
untracked physical output must still be implemented and costed. These are
counts for the displayed protocols, not an optimal architecture bound.

The [unitary-braid magic result NR-R17](braided-magic.md) concerns a
different endpoint: a useful non-Clifford gate or raw logical magic state.
Protected Ising braids and fusion records alone cannot supply its coherent
order router. A proposed hybrid spin/position interface also enables
ordinary loop and exchange-interferometer factories; their complete
physical Abelian phases and position-selection losses are essential.
The next comparison needs a named anyon/charge model, a complete
trajectory instrument and distilled/injected logical output at fixed
error per factory space and time. An ideal magic witness or a non-Abelian
fringe does not establish that cost advantage.

The [rewinding-cost analysis in NR-R05](obstructions.md#nr-r05) supplies
another stopping boundary. A particular published adaptive walk completes
almost surely but has infinite mean query count, and independent loss
reduces its delivered success. The tested fixed-axis optical evolution
also admits an ordinary Pauli echo. Compare known-perturbation checks,
ordinary extra-query routing and modern unitary-inversion protocols
before translating a conditional rewinding experiment into a useful
recovery-rate claim. This finding concerns the stated walk and access
model, rather than every quantum rewinding algorithm.

Unknown analogue internals do not automatically prevent ordinary checks.
If a known implementable involution commutes with the ideal Hamiltonian,
the same before/after check in NR-R06 preserves its full evolution and
tests arbitrary interval faults without learning that evolution. Its
controlled helper and readout costs remain real. Short-time coherent
order symmetrization must also be compared with randomized ordering and
ordinary symmetric splitting, including available half-duration controls.
[Vrajitoarea et al.](https://arxiv.org/abs/2602.06108) demonstrate genuine
quantum-controlled many-body dynamics and a many-body echo, but do not
supply two opaque switchable many-body modules. Similarly,
[Kraft et al.](https://doi.org/10.1103/s96t-n8tx) learn Hamiltonian and
dissipative parameters on trapped-ion hardware: their long-time validation
uses classical simulation, while their measurement-only bounds concern
short times. Large Hilbert-space dimension alone is not a calibration
lower bound for these structured generators.

A separate conditional construction concerns coherent subroutine dispatch
through a dephased program register. The
[quantum control machine](https://arxiv.org/abs/2304.15000) motivates coherent
control-flow semantics, but is a theoretical architecture and does not supply
a native faulty instruction interface. The familiar self-switch correction
for anticommuting random unitaries already appears in
[Chiribella and Kristjánsson](https://arxiv.org/abs/1812.05292).
The [dispatch result NR-R12](dispatch.md) gives the exact correction and
the full-output ordinary two-versus-three-call boundary for its opaque
indexed-unitary interface. It also includes a four-call ordinary simulation
in two parallel rounds. Writing the prior mechanism as program-counter
recovery does not establish novelty or a hardware benefit. A surviving
dispatch proposal must specify its native
ports, distinct switchable noisy slots, reusable calibration, direct compiled
and ordinary three/four-call simulations, parallel execution and controller
occupancy. Repeating one noisy processor at two fixed chronological times
does not by itself supply a switch of two independent noisy slots.
Conversely, quasistatic counter-phase noise can cancel in two ordinary
repetitions. A proposed temporal-noise model must preserve the required
switch coherence without inadvertently granting that ordinary echo.

The dispatch note now gives an explicit consistent dilation: private,
coherent visit heads select retained independent fault coins by invocation
number. Both switch histories finish with the same heads, while ordinary
repeats consume fresh coins. This requires protected quantum event memories,
reversible addressing and no exported timestamps. With ideal routing and
equal exponential head dephasing, visibility $0.97$ requires head $T_2$
about $66$ times the separation between visits. It resolves logical
consistency without establishing a cheap native module. Rewind, coin readout
and reset controls cannot be withheld if the operator actually has them.

The same note supplies a stronger physical comparison for time-varying
classical phase fields. Ordinary paths that revisit one station in each
arm produce the same corrected quantum output for every phase history as
paths that interchange stations. For independent identical centered Gaussian
fields, the ordinary alternatives match the best all-outcome postdecoder;
with nonnegative temporal correlation, ordinary same-order filtering also
dominates the entire accepted Bell-fidelity frontier. These statements
require the specified vacuum extension, local delay loops and matched loss
and helper assumptions. They do not cover nonclassical bath backaction.

Noncommuting conditional dynamics have a real constituent model:
[Taminiau et al.](https://arxiv.org/html/1309.5452) give electron-controlled
nuclear Hamiltonians $H_0=\omega_L I_z$ and
$H_1=(\omega_L+A_\parallel)I_z+A_\perp I_x$. An electron flip after
conditional free evolution has the algebraic dispatcher form.
[Hernández-Gómez et al.](https://arxiv.org/html/1808.08222) distinguish
coherently coupled nuclei from a residual stochastic bath and show when
classical bath predictions fail under changed controls. Neither source
supplies two matched routable processors acting on the same nuclear target,
the required coherent vacuum interface, or an event-indexed fault reservoir.
Two NV centres with separate attached memories cannot be substituted for
that missing port. Their calibrated decoupling sequences remain ordinary
competitors, not evidence for switch recovery.

The application must also require the target computation. A standard XOR
lookup squares to the identity; stationary analog evolution squares to a
direct evolution for twice as long. The Quantum Control Machine's
implementation uses fixed, known primitive gates (§5.3, footnote 5), so
its program counter does not establish unknown reusable subroutine ports.
[Oracle Distillation](https://arxiv.org/abs/2609.31596) is a current ordinary
weak-query/QEC comparator for structured unknown Boolean families. It grants
ideal helper operations and memory and leaves physical QRAM noise shaping
open; it is not a theorem for arbitrary unknown unitaries or a demonstrated
native processor.

The [composite-lookup screen](native-lookups.md) tests a different useful
target: a clean phase marking the intersection of two classical datasets.
Measurement-based uncomputation gives an exact ordinary protocol with
mean $2.5$ reads; immediate rejection allows $80\%$ perfect accepted output
at mean two reads. The obvious balanced switch followed by junk-only
erasure succeeds at most one third of the time. A maintained intersection
table is a further ordinary baseline when the operator owns both datasets.
That displayed switch protocol should therefore not be pursued as a winner.

A [superconducting coherent-router demonstration](https://arxiv.org/abs/2505.13958)
provides a concrete small testbed for route–call–return instruments,
including terminal address erasure selection. Its address readout and
classical discard of level-$1$ shots do not demonstrate a nondestructive
binary code-space measurement preserving an unknown address. Data sites
start in physical $|0\rangle$, not an orthogonal vacuum sector. Applying
arbitrary unknown leaf gates also changes unselected sites and can leave
which-address junk; a known leaf phase preserving $|0\rangle$ is a different,
more structured interface.

There is already a precise ordinary screen for the router's address-fault
alarm. Its ideal controlled swaps leave the address unchanged. Switching a
fixed noisy route with a known diagonal address involution has exactly the
same full flagged instrument as an ordinary controlled-phase check sandwich
using one route call. On code-supported inputs, code-versus-leakage detection
needs only a single controlled phase after the route. Pure diagonal address
dephasing triggers neither construction. The
[native address-check proof](architecture-baselines.md#nr-r06) and exact
qutrit replay state the shared-map and helper-cost conditions.

The next native calculation must use the actual noisy gate sequence and
preserved output registers, including leakage, unselected-site states and
reset/readout records. Compare the measured cost of the single post-check
and full check sandwich with any proposed order router. Across these
platforms, charge complete shot time, accepted yield and hardware occupancy;
one control readout does not automatically beat two destructive detections.
Calibration must be amortized within the actual drift window. An exclusive
switch claim cannot follow from granting it a clean known symmetry or a
coherent vacuum port absent from the ordinary hardware. A surviving task
must also beat direct compiled control, conditional uncomputation and reuse.
No present screen establishes that advantage.

### Nonlinear photonic evolution: the next complete-instrument test

A repeated passive photonic operation is not enough to supply an expensive
quantum workload. For a known single-particle mode matrix $M$, compute and
compile $M^2$ into one freely programmable mesh. Second quantization obeys
$\Gamma(M)^2=\Gamma(M^2)$ on every photon-number sector: both sides transform
each creation operator by $M^2$ and preserve vacuum. Thus an exponentially
large multiphoton Fock space does not invalidate this shortcut. A
[20-mode universal processor](https://doi.org/10.22331/q-2023-08-01-1071)
is a concrete instance of the programmable interface; actual programming,
calibration drift and compilation errors must be included.

[Nielsen et al.](https://doi.org/10.1038/s41467-025-66205-w) provide a more
substantive next model: two-photon nonlinear scattering interleaved with
programmable linear optics, used for anharmonic molecular dynamics.
Nonlinearity removes the passive matrix-squaring shortcut. The published
platform has one quantum dot, however, and its measured nonlinear response
includes spectral-mode distortion. A fitted nonlinear fringe phase is not
by itself a reusable controlled-phase channel. Two matched independent
modules and an order router cannot be assumed from that experiment.

The [scattering comparisons in NR-R11](communication.md#nr-r11) now separate
three cases. Bare detuning-only pairs with common monitored coupling commute
on the entire accepted two-photon field. Unequal couplings escape that
identity and give a conditional gate on a specified correlated relative-mode
code. Its best resonant endpoint is already ordinary serial scattering;
for the stated finite-pulse target, a kernel-transpose identity preserves
the same correct-output weight in the ordinary order. Conditional error
rejection alone is therefore insufficient. The minus branch also annihilates
the vacuum and one-photon sectors, preventing its use as a heralded dual-rail
controlled-phase gate in the specified routing. An ideal whole-pair passive
vacuum herald retains both photons at half the abstract branch yield;
unmonitored loss can falsely herald missing photons. An independent order
ancilla can be measured without consuming the targets, but its preparation,
coupling, storage and readout must be supplied and charged.

Photon-preserving bath noise is a separate case. If nonvacuum bath records
resolve the early and late windows while the empty-record products commute,
ordinary randomized same-order delayed paths reproduce the complete measured
order-flag and photon-output instrument. This comparison uses three global
windows instead of two, with the same two occupied traversals; its extra
delay, route loss and visibility matter. A Markov model alone does not imply
disjoint records for finite pulses with long scattering tails. The proof
now supplies a [uniform finite-emitter record guard](communication.md#nr-r11-uniform-record-guard)
for number-conserving vacuum-Markov models with a positive radiative Gram
floor and an actual vacuum-preserving ground. Gaussian truncation and all
route guards enter a complete-instrument error and clock budget. Nominal
two-emitter parameters illustrate that test; they do not establish a measured
confidence region or split a collective device into independent slots.
Retained phonon modes, overlapping histories and unmodeled delayed feedback
remain outside that reduction. Both protocols must meet the same declared
accuracy before their extra-window delay and visibility costs are compared.

There are now more specific physical starting points than an assumed pair
of copies of Nielsen's processor.
[Hallacy et al.](https://arxiv.org/abs/2511.07640) independently tune two
chiral dots in a shared waveguide and measure spin-dependent photon
correlations. Reversing propagation exchanges directional couplings and
optical transitions; it does not automatically supply the same two local
modules in reverse order. [Hansen et al.](https://arxiv.org/abs/2605.18525)
demonstrate collective few-photon transport through coupled emitters with
both forward and backward outputs. Their device is a joint scatterer, so
its coherent reflection and shared dynamics cannot be replaced by a product
of independent forward channels.

The [reciprocal two-emitter model in NR-R11](communication.md#nr-r11)
now supplies an explicit one-photon starting point using the measured
device geometry. Its transmission includes coherent multiple reflections,
so multiplying independent single-emitter transmissions misses feedback.
Opposite transmission directions nevertheless agree in the specified
bare reciprocal model. Reflections, two-photon interactions and inelastic
bath records require their own complete operators; directional emission
from an excited pair is a different initial-state experiment.

The [Rydberg stored-photon screen](communication.md#nr-r11-rydberg-memory)
supplies another actual nonlinear memory task. Its fixed-configuration,
independent-probe instruments commute before any records are discarded;
an output photon deficit is not a valid success herald. A distinct next
test needs measured non-diagonal spin-wave dynamics or shared probes,
with ordinary mixing, retrieval and pulse controls admitted.
The [coherent exchange model](communication.md#nr-r11-rydberg-exchange)
now provides ordinary one-collision memory preparation and two-collision
delivery benchmarks with full record kernels. The specific next
experiment measures retained memory/rail coherence and false heralds;
population hopping alone does not certify that memory resource.

The next test is the full input-output model of one such actual device.
Prespecify a useful detuning or spin-setting decision, or a delivered
few-photon state/gate, and compare ordinary phase/correlation measurements,
pulse optimization, spectral selection and coherent delayed paths. Retain
all output ports, emitter and phonon records, and the valid-output herald.
If a reversed route changes the local interaction, compare that physical
process directly rather than importing the abstract channel-SWITCH bound.
Charge source, routing, storage, reset, selection and every rejected launch.
A significant advantage on this nonlinear platform remains unestablished.
