# Rook support: an exact scalar reduction and a GYNI-specific common-lift obstruction

The blockwise rank-one problem has an exact optimization with only
2K scalar weights. It does **not** solve the complete GYNI process problem.
The normalization couplings genuinely prevent using its replacements jointly:
an integer-certified, objective-specific K=2 separation below rules out every
simultaneous row/column PSD-clique replacement at equal score on that support.
There is no finite-attainment or unrestricted-value claim.

<a id="p2-r11"></a>

## 1. Exact rank-one reduction with every diagonal block fixed

Let vertices be (j,k), 1<=j,k<=K. A Hermitian block matrix W has rook support
when W_(jk,j'k')=0 whenever j!=j' and k!=k'. Its vertex blocks can have any
finite dimension, including the physical input-spin dimension four. Fix
W_(jk,jk)=B_jk>=0 and a vector v_jk at each vertex. Write v for their direct
sum and q_jk=v_jk* B_jk v_jk.

Then exactly

    max { v*Wv : W>=0, rook support, diagonal B }
      = V(q)
      = inf { sum_jk q_jk lambda_jk : lambda_jk>0,
               sum_k 1/lambda_jk <=1 for every j,
               sum_j 1/lambda_jk <=1 for every k }
      = [ max { sum_jk sqrt(q_jk(a_j+b_k)) : a,b>=0,
                 sum_j a_j+sum_k b_k=1 } ]^2.                 (1)

For positive q the infimum is attained; zero entries are included by
continuity. The last optimization has only 2K nonnegative scalar variables.
Moreover, an optimum W can be chosen as a sum of PSD matrices supported on
individual rows or columns, while preserving every complete block B_jk.
This is a statement about one uncoupled PSD block.

### Reduction to a scalar matrix

For any feasible W, C_uv=v_u*W_uv v_v is a scalar PSD rook matrix with diagonal
q and objective 1*C1. Conversely, given any such C, put

    z_u=B_u v_u/q_u,
    W_uv=z_u C_uv z_v* + delta_uv [B_u-B_u v_u v_u* B_u/q_u]. (2)

The second term is PSD and annihilates v_u, by Cauchy-Schwarz in the
B_u-inner product. Thus (2) is positive, has exactly the required diagonal,
retains rook support and has the same objective. When q_u=0, positivity gives
B_u v_u=0 and the u-th row of C is zero; set z_u=0 and retain the full B_u as
the diagonal residual.

### Exact PSD completion from fractional matchings

The scalar SDP dual asks for a PSD completion S with

    S_uu=lambda_u-1,
    S_uv=-1 for distinct vertices in the same row or column.  (3)

Necessity of the reciprocal constraints in (1) follows by inspecting each
clique: diag(lambda)-11*>=0 iff the reciprocal sum is at most one.
For sufficiency, w_jk=1/lambda_jk is doubly substochastic. Decompose it as a
convex combination of partial permutation matrices, equivalently a
probability distribution mu on matchings M of the bipartite K-by-K graph.
This elementary matching decomposition follows by padding w to the doubly
stochastic 2K-by-2K matrix

    [ w                         diag(1-row_sums(w)) ]
    [ diag(1-column_sums(w))     w^T                 ]

and decomposing a doubly stochastic matrix into permutation matrices.
For each vertex u define a vector indexed by those matchings,

    h_u(M)=sqrt(mu_M) [lambda_u 1_(u in M)-1].

The Gram matrix of the h_u has diagonal lambda_u-1. Two distinct adjacent
rook vertices cannot occur in one matching, so their Gram entry is -1.
This proves the required completion (3), without a chordality assumption.
Strong SDP duality gives the first scalar formula in (1).

The scalar convex program has a strictly feasible point. Its Lagrange dual,
with row/column multipliers alpha_j,beta_k>=0, is

    max 2 sum_jk sqrt(q_jk(alpha_j+beta_k))
             -sum_j alpha_j-sum_k beta_k.

Optimizing the common scale of alpha,beta gives the last expression in (1).
The same reciprocal constraints are the dual of the scalar row/column
clique-sum cone, proving its optimum is also V(q). Alternatively, at a
positive-q KKT point set

    r_jk=q_jk alpha_j/(alpha_j+beta_k),
    c_jk=q_jk beta_k/(alpha_j+beta_k).

The rank-one row matrices generated by sqrt(r_jk), together with the rank-one
column matrices generated by sqrt(c_jk), attain V(q). Lifting them by (2)
preserves each complete B_jk and gives the claimed block clique sum.

## 2. The full physical normalization retains cross-label information

For the sixteen outcome-dephased physical blocks W_lm, let j,j' denote
Alice angles and k,k' Bob angles. Besides rook support, the audited
projector requires:

- If j!=j', the entries W_lm[(j,k),(j',k)] are independent of m, and their
  sum over k of the Bob-input partial trace is zero
- If k!=k', the entries W_lm[(j,k),(j,k')] are independent of l, and their
  sum over j of the Alice-input partial trace is zero
- The angle-diagonal blocks have an additive output-label form
  W_lm[(j,k),(j,k)]=C_jk+A_l,jk+B_m,jk, with sum_l A_l,jk=0 and
  sum_m B_m,jk=0
- sum_k Tr_B A_l,jk=0 for every l,j, and sum_j Tr_A B_m,jk=0 for every m,k
- sum_jk Tr C_jk=1

These conditions, Hermiticity, and PSD are equivalent to P(W)=W and
Tr W=16. They follow by decomposing the local space into D, R-D and I-R.
The replacement (2) has no reason to preserve the shared off-angle entries
or their matrix-valued zero sums. The next section proves that no choice of
common clique replacements can always repair this defect at equal GYNI score.

## 3. Exact GYNI separation: common normalized clique lifts are impossible

Fix the same two angles at both parties, with exact trigonometric data

    (cos(theta_1),sin(theta_1))=(15/17,8/17),
    (cos(theta_2),sin(theta_2))=(8/17,15/17).

Let C_rook be the full audited physical cone. Let C_clique be its subset in
which every W_lm is a sum of PSD matrices supported on one Alice-angle row
or one Bob-angle column. The following bounds have integer-only certificates:

    max_(W in C_rook) <G,W>
       >= 41466694494597 / 66827490688000
        = 0.6205035393023225...,

    max_(W in C_clique) <G,W>
       <= 6183 / 10000 = 0.6183.

The exact strict gap is

    736285011033 / 334137453440000
      = 0.002203539302322517... .                         (4)

The lower process has sixteen strictly positive 16-by-16 rational blocks,
satisfies the complete projector and trace constraints, and therefore has
the previously proved completely positive lift to a full physical process.

The upper is a rational array F satisfying

    P(F)=(6183/160000) I.

For all sixteen labels, all two rows and all two columns, the 8-by-8
principal compression of F_lm-G_lm is strictly positive. Consequently every
PSD clique-sum W obeys

    <G,W> <= <F,W>
           = <P(F),W> = (6183/160000) Tr W = 6183/10000.

There are no game-symmetry assumptions in this certificate: all sixteen
blocks and all 64 clique slacks are checked. The discovery solve used game
symmetry only to locate the candidate. In particular, the upper covers
replacement processes with different diagonal blocks as well.

Thus the rank-one objective in section 1 does not permit a simultaneous
normalization-preserving clique lift, even for the actual GYNI objective.
This excludes that proposed vector-valued/fractional-matching shortcut on
this support. It does not exclude a different operator reduction, nor an
optimizer replacement allowed to change the angle support.

## 4. A shorter exact physical non-clique witness

There is also an analytic witness independent of the game angles. At K=2,
write X,Z for Pauli matrices, with local order angle then input spin. Set

    H1=(X tensor X)_A tensor (Z tensor I)_B,
    H2=(Z tensor Z)_A tensor (X tensor I)_B,
    H=H1+H2,
    W_lm=(3I+2H)/48 for all sixteen labels.

H1,H2 are Hermitian involutions that anticommute, so H^2=2I. Each W_lm is
strictly positive with trace one. H1 lies in (I-R)_A tensor (R-D)_B and H2
in (R-D)_A tensor (I-R)_B; hence the entire array is exactly normalized.

Every row or column compression H_C is an involution, so H_C<=I_C.
Therefore all PSD clique sums Y satisfy Tr(HY)<=Tr Y. But this process has

    Tr(H W_lm)/Tr(W_lm)=4/3.

It is outside the clique-sum cone. Unlike (4), this short witness alone does
not establish an obstruction for preserving the GYNI objective; section 3
supplies that additional assertion.

`check_rook_exact.py` verifies this construction, the full physical
projector, a rational fractional-matching completion, and an exactly sharp
nonuniform scalar example. Its output is `rook_exact_checks.json`.

## 5. What remains open

The scalar reduction is exact for a fixed-diagonal individual block, and the
common-clique shortcut is rigorously ruled out for GYNI. Neither result bounds
the number of angles in a full-process optimizer. A successful reduction must
retain the noncommutative cross-label/partial-trace coupling that section 3
separates from all common scalar clique lifts.
