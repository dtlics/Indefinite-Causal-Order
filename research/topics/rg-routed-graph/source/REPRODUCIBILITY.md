# Reproducibility scope

Run the maintained `verify_proof.py` from `source/`. Integrity verifies the
canonical proof references, result anchors and exact current file hashes.
Core/full tiers execute their listed certificate scripts in a temporary copy.
The uniform private-ancilla and graph arguments remain analytic proofs;
finite calibrations are not substitutes for them.
